# 10.3. Socket.IO Schema

A Joi schema for validating the `SocketIOServerConfig` handed to `SocketIOModule.registerAsync`. Exported so consumers can validate their own config (e.g. via `@ValidateReturnValue`) before registering the module.

## Import

```typescript
import { SocketIOConfigSchema } from '@triplef/socketio';
```

## Fields

### `port`

| Field | Type | Constraints |
|-------|------|-------------|
| `port` | `number` | Optional |

### `opts`

| Field | Type | Constraints |
|-------|------|-------------|
| `cleanupEmptyChildNamespaces` | `boolean` | Required |
| `maxHttpBufferSize` | `number` | Required |
| `pingInterval` | `number` | Required |
| `pingTimeout` | `number` | Optional |
| `connectTimeout` | `number` | Required |
| `allowEIO3` | `boolean` | Required |
| `transports` | `string[]` | `websocket`, `polling`, `webtransport` |
| `cors.origin` | `string` | `*` allowed |
| `cors.credentials` | `boolean` | Required |
| `cors.methods` | `string[]` | `GET`, `POST` |

Both `port` and `opts` are optional — an empty config validates.

## Usage

```typescript
import { Injectable } from '@nestjs/common';
import { ValidateReturnValue } from '@triplef/config-factory/validate-return-value';
import { SocketIOConfigSchema } from '@triplef/socketio';

@Injectable()
export class SocketIOConfigService {
  @ValidateReturnValue(SocketIOConfigSchema)
  get options() {
    return {
      opts: {
        transports: ['websocket', 'polling'],
        cors: { origin: '*', credentials: true, methods: ['GET', 'POST'] },
      },
    };
  }
}
```
