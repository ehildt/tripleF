# 12.3. Agent Tools

`@triplef/agent/tools` — the model-callable tool factories, one per tool, created only when the provider behind them is enabled (gating rules live in the harness — see **1.2**). Factories are **dependency-injected**: they receive their clients/credentials per call site, so the same tool compiles into the server harness with real HTTP clients and into tests with fakes.

## Import

```typescript
import { /* factories */ } from '@triplef/agent/tools';
```

## Provider families

| Family | Directory | Tools |
| --- | --- | --- |
| **Serper** | `serper/` | `createSerperWebSearch` … → `serperWebSearch`, `serperImageSearch` (720p min / 1440p preferred), `serperNewsSearch`, `serperPlacesSearch`, `serperShoppingSearch`, `serperBusinessReviewsSearch` (Google Maps reviews by `cid`/`placeId`), `serperVideoSearch`, `serperWebpageScrape` (scraped page text) |
| **Bright Data** | `bright-data/` | `brightDataWebSearch`, `brightDataImageSearch`, `brightDataNewsSearch`, `brightDataPlacesSearch`, `brightDataShoppingSearch`, `brightDataVideoSearch`, `brightDataWebpageScrape` (Web Unlocker) |
| **YouTube** | `youtube/` | `youtubeVideoSearch` — `search.list` + batch `videos.list` enrichment (duration, view count, channel, direct thumbnail) — Data API v3 |
| **Built-ins** | `web-fetch/` | `webFetch` — fetch a page and extract readable text (Readability + turndown) |
| **Image variants** | `image-variants/` | Tools that let the model request preprocessing variants (grayscale/denoised/sharpened/CLAHE) of user images — see PProc in **1.1**/**1.8** |
| **Memory** | `memory/` | The five memory tools (below) |

> EODHD market-data tools stay **server-local** (`apps/server/src/modules/ai-sdk/tools/sources/eodhd/`) because they couple to the server's stock-data cache — see **1.1**/**4.7**.

## Memory tools (`memory/`)

The five `MEMORY_TOOL_NAMES`, each created with a `MemoryToolScope` threaded per request — partition/cognition binding plus provenance ids, so a tool can never cross space boundaries:

| Tool | Behavior |
| --- | --- |
| `memory-partition-remember` | Store ONE self-contained fact record (embed + upsert; deterministic id — restating verbatim updates in place). Tags are the recall filter vocabulary; `category` groups tags into one topic family. |
| `memory-partition-recall` | Multi-variant semantic recall of the fact partition (full text + per-sentence). Verbatim quotes are the delete identity — records expose no ids. |
| `memory-partition-delete` | Delete an exact verbatim record. |
| `memory-cognition-remember` | Store one derived insight into the AI's cognition space. |
| `memory-cognition-forget` | Wipe the AI's understanding of the user (profile + insights + episodes + convictions) when asked to forget them. |

## Tool summaries (`tool-factory.ts`)

Every tool is wrapped by `withSummary(tool, summarize)` so results get a compact, shape-aware log summary (`resultCount`, `sources`, `sampleImageUrls`, `contentLength`, `found`) — long logs without leaking full payloads. Default summarizers: `summarizeResults`, `summarizeContent`, `summarizeFound`, `defaultSummarize`.

## Shared helpers

`apply-locale-params`, `apply-recency-param`, `localized-query-suffix` (locale/recency grounding from the request's `language`), `fetch-with-timeout` (+ `search-timeout` constant), `image-size-buckets`, `store-host-token`, `is-google-host-url`, `pick-merchant-result`, `serper-shop-links`, `build-youtube-thumbnail-url`, and the recency/standalone-query constants — small, individually tested helpers the factories compose.
