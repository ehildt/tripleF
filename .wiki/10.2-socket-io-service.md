# 10.2. Socket.IO Service

A NestJS service wrapping the Socket.IO server for room management and event handling. All methods return `this` for chaining.

## Import

```typescript
import { SocketIOService } from '@triplef/socketio';
```

## Methods

| Method | Description |
| --- | --- |
| `emit(event, message)` | Broadcast to all connected clients |
| `emitTo(event, room, message)` | Broadcast to a specific room |
| `on(event, cb)` / `on(eventMap)` | Subscribe to incoming events |
| `joinRoom({ socket, data, ack })` | Make a socket join a room |
| `leaveRoom({ socket, data, ack })` | Make a socket leave a room |
| `to(room)` / `in(room)` | Modifier: target a room |
| `except(room)` | Modifier: exclude a room |
| `timeout(ms)` | Modifier: acknowledgement timeout |
| `fetchSockets(cb)` | Fetch matching sockets |
| `socketsJoin(rooms)` / `socketsLeave(rooms)` | Move all sockets |
| `disconnectSockets(close?)` | Disconnect matching sockets |
| `close(cb?)` | Close the server |
| `of(nsp, cb)` | Access a namespace |
| `use(fn, cb?)` | Register middleware |

## Usage

```typescript
import { Injectable } from '@nestjs/common';
import { SocketIOService } from '@triplef/socketio';

@Injectable()
export class ChatService {
  constructor(private readonly socketService: SocketIOService) {}

  send(room: string, message: unknown) {
    this.socketService.emitTo('message', room, message);
  }
}
```

The underlying server is exposed via the `io` getter; the resolved config via `config`.
