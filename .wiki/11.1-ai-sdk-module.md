# 11.1. AI SDK Module

A dynamic module that wires `AiSdkService` to caller-supplied `AiSdkConfig`.

## Import

```typescript
import { AiSdkModule } from '@triplef/ai-sdk';
```

## Interface

```typescript
type AiSdkModuleProps = {
  global?: boolean;
  inject?: any[];
  useFactory: (...deps: any[]) => AiSdkConfig | Promise<AiSdkConfig>;
};
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `global` | `boolean` | `false` | If `true`, makes the service available throughout the application without explicit import |
| `inject` | `any[]` | — | Providers injected into `useFactory` |
| `useFactory` | `(...deps: any[]) => AiSdkConfig \| Promise<AiSdkConfig>` | — | Factory returning the AI SDK config |

## Usage

```typescript
import { Module } from '@nestjs/common';
import { AiSdkModule } from '@triplef/ai-sdk';
import { createOllama } from 'ollama-ai-provider-v2';

@Module({
  imports: [
    AiSdkModule.registerAsync({
      global: true,
      useFactory: () => ({
        streamChunkTimeoutMs: 60_000,
        streamTotalTimeoutMs: 600_000,
        generateTotalTimeoutMs: 300_000,
        enableSmoothStream: true,
        createModel: (name) =>
          createOllama({ baseURL: 'http://127.0.0.1:11434/api' })(name),
      }),
    }),
  ],
})
export class AppModule {}
```

The env-driven config and the model provider live in the consuming app — the library ships no config service, reads no environment variables, and knows nothing about any specific provider.
