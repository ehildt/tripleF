# 9.2. BullMQ-Logger Module

A dynamic module that wires `BullMQLoggerService` to caller-supplied pino `LoggerOptions`.

## Import

```typescript
import { BullMQLoggerModule } from '@triplef/bullmq-logger';
```

## Interface

```typescript
interface BullMQLoggerModuleOptions {
  global?: boolean;
  inject: Array<any>;
  useFactory: (...deps: any[]) => Promise<LoggerOptions> | LoggerOptions;
}
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `global` | `boolean` | `false` | If `true`, makes the service available throughout the application without explicit import |
| `inject` | `Array<any>` | — | Providers injected into `useFactory` |
| `useFactory` | `(...deps: any[]) => Promise<LoggerOptions> \| LoggerOptions` | — | Factory returning the pino `LoggerOptions` |

## Usage

```typescript
import { Module } from '@nestjs/common';
import { BullMQLoggerModule } from '@triplef/bullmq-logger';
import { MyLoggerConfigService } from './logger-config.service';

@Module({
  imports: [
    BullMQLoggerModule.registerAsync({
      global: true,
      inject: [MyLoggerConfigService],
      useFactory: (config: MyLoggerConfigService) => config.options,
    }),
  ],
})
export class AppModule {}
```

The env-driven config lives in the consuming app — the library ships no config service and reads no environment variables.
