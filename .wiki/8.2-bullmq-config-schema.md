# 8.2. BullMQ Config Schema

A Joi schema for validating the `BullMQConfig` handed to `BullMQModule.registerAsync` (connection + default job options). Exported so consumers can validate their own config (e.g. via `@ValidateReturnValue`) before registering queues.

## Import

```typescript
import { BullMQConfigSchema } from '@triplef/bullmq';
```

## Fields

### `connection`

| Field | Type | Constraints |
|-------|------|-------------|
| `enableReadyCheck` | `boolean` | — |
| `host` | `string` | Valid hostname |
| `password` | `string` | Empty string allowed |
| `username` | `string` | Empty string allowed |
| `port` | `number` | `1..65535` |
| `connectTimeout` | `number` | `>= 1000` |
| `commandTimeout` | `number` | `>= 1000` |
| `retryStrategy` | `any` | — |
| `tls` | `object \| null` | `rejectUnauthorized`, `ca`, `cert`, `key`, `passphrase` |

### `defaultJobOptions`

| Field | Type | Constraints |
|-------|------|-------------|
| `delay` | `number` | `>= 0` |
| `lifo` | `boolean` | — |
| `priority` | `number` | `>= 0` |
| `attempts` | `number` | `1..50` |
| `stackTraceLimit` | `number` | `>= 1` |
| `removeOnComplete` | `{ age?, count? }` | — |
| `removeOnFail` | `{ age?, count? }` | `>= 0` |
| `backoff` | `{ type: 'exponential' \| 'fixed', delay? }` | `>= 0` |

Both `connection` and `defaultJobOptions` are optional — an empty config validates.

## Usage

```typescript
import { Injectable } from '@nestjs/common';
import { ValidateReturnValue } from '@triplef/config-factory/validate-return-value';
import { BullMQConfigSchema } from '@triplef/bullmq';

@Injectable()
export class BullMQConfigService {
  @ValidateReturnValue(BullMQConfigSchema)
  get options() {
    return {
      connection: { host: 'localhost', port: 6379 },
      defaultJobOptions: { attempts: 3, backoff: { type: 'exponential', delay: 1000 } },
    };
  }
}
```
