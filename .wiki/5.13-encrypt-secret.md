# Encrypt Secret / Decrypt Secret

AES-256-GCM encryption of UTF-8 secrets with a **self-describing, versioned payload** — the cipher behind Settings-persisted provider keys (see **1.5 — Secrets cipher**).

## Import

```typescript
import { encryptSecret } from "@triplef/helpers/encrypt-secret";
import { decryptSecret } from "@triplef/helpers/decrypt-secret";
```

## Payload format

```
v1.<keyFingerprint>.<iv>.<authTag>.<ciphertext>   (base64url parts)
```

- **AES-256-GCM** — OWASP first-choice authenticated mode; tampering fails decryption at the auth tag.
- **Fresh random 96-bit IV per call** (CSPRNG) — GCM nonce reuse is catastrophic; random 96-bit IVs are the NIST SP 800-38D recommended construction.
- **Key fingerprint embedded** — the first 8 hex chars of the key's SHA-256 (see [5.14. Key Fingerprint](5.14-key-fingerprint.md)) identifies *which* key encrypted the payload, without leaking key material.

## Signatures

```typescript
function encryptSecret(plaintext: string, key: Buffer): string;

function decryptSecret(
  payload: string,
  keysByFingerprint: ReadonlyMap<string, Buffer>
): string;
```

## Behavior

- `decryptSecret` throws on malformed payloads, unknown key fingerprints, and GCM auth-tag mismatches (tampered or wrong-key data) — callers decide how to handle the failure.
- **Key rotation** is the reason for the fingerprint: the server's secrets module keeps a key ring `{ fingerprint(current) → current, fingerprint(previous) → previous }` while `TRIPLEF_SECRETS_KEY_PREVIOUS` is set, re-encrypts stored payloads with the active key on boot, then the previous key can be dropped. See **1.8**.

## Example

```typescript
const payload = encryptSecret(apiKey, masterKey);      // store this
const apiKey2 = decryptSecret(payload, keysByFingerprint);
```
