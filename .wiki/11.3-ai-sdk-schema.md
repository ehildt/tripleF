# 11.3. AI SDK Schema

A Joi schema for validating the serializable part of `AiSdkConfig`. Exported so consumers can validate their own config (e.g. via `@ValidateReturnValue`) before registering the module.

## Import

```typescript
import { AiSdkConfigSchema } from '@triplef/ai-sdk';
```

## Fields

| Field | Type | Constraints |
|-------|------|-------------|
| `streamChunkTimeoutMs` | `number` | Integer, `>= 1000` |
| `streamTotalTimeoutMs` | `number` | Integer, `>= 1000` |
| `generateTotalTimeoutMs` | `number` | Integer, `>= 1000` |
| `enableSmoothStream` | `boolean` | Optional |

All fields are optional — an empty config validates. The `createModel` factory is not part of the schema (it is a function supplied by the app's `useFactory`, not a serializable value).

## Usage

```typescript
import { Injectable } from '@nestjs/common';
import { ValidateReturnValue } from '@triplef/config-factory/validate-return-value';
import { AiSdkConfigSchema } from '@triplef/ai-sdk';

@Injectable()
export class AiSdkConfigService {
  @ValidateReturnValue(AiSdkConfigSchema)
  get options() {
    return {
      streamChunkTimeoutMs: 60_000,
      streamTotalTimeoutMs: 600_000,
      generateTotalTimeoutMs: 300_000,
      enableSmoothStream: true,
    };
  }
}
```
