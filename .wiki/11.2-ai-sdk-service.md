# 11.2. AI SDK Service

A provider-agnostic NestJS service wrapping the Vercel AI SDK.

## Import

```typescript
import { AiSdkService } from '@triplef/ai-sdk';
```

## AiSdkService

| Method | Description |
| --- | --- |
| `streamChat(params)` | Stream a chat completion (`streamText`; optional word-level smooth streaming via `smoothStream`) |
| `generateChat(params)` | Generate a chat completion (`generateText`) |
| `generateWithTools(params)` | Generate with tool calls, capturing `ToolResult`s |

The model is resolved per call via the config's `createModel` factory (supplied by the app). Provider-specific options are passed through via `params.providerOptions`.

## Usage

```typescript
import { Injectable } from '@nestjs/common';
import { AiSdkService } from '@triplef/ai-sdk';

@Injectable()
export class ChatService {
  constructor(private readonly aiSdk: AiSdkService) {}

  async stream(messages: InputMessage[]) {
    return this.aiSdk.streamChat({ model: 'llama3.2', messages });
  }
}
```
