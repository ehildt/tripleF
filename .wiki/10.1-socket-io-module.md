# 10.1. Socket.IO Module

A dynamic module that wires `SocketIOService` to caller-supplied `SocketIOServerConfig`, plus an `attach()` helper that auto-detects Fastify or Express.

## Import

```typescript
import { SocketIOModule } from '@triplef/socketio';
```

## Interface

```typescript
type SocketIOModuleProps = {
  global?: boolean;
  inject?: any[];
  useFactory: (...args: any[]) => SocketIOServerConfig | Promise<SocketIOServerConfig>;
};
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `global` | `boolean` | `false` | If `true`, makes the service available throughout the application without explicit import |
| `inject` | `any[]` | — | Providers injected into `useFactory` |
| `useFactory` | `(...args: any[]) => SocketIOServerConfig \| Promise<SocketIOServerConfig>` | — | Factory returning the Socket.IO server config |

## Usage

```typescript
import { Module } from '@nestjs/common';
import { SocketIOModule } from '@triplef/socketio';
import { MySocketIOConfigService } from './socket-io-config.service';

@Module({
  imports: [
    SocketIOModule.registerAsync({
      global: true,
      inject: [MySocketIOConfigService],
      useFactory: (config: MySocketIOConfigService) => config.options,
    }),
  ],
})
export class AppModule {}
```

## Attaching the server

`SocketIOModule.attach(app, fsio?)` auto-detects the HTTP adapter:

```typescript
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter, NestFastifyApplication } from '@nestjs/platform-fastify';
import { SocketIOModule } from '@triplef/socketio';

void (async () => {
  const app = await NestFactory.create<NestFastifyApplication>(AppModule, new FastifyAdapter());
  await SocketIOModule.attach(app);
  await app.listen({ port: 3000 });
})();
```

The env-driven config lives in the consuming app — the library ships no config service and reads no environment variables.
