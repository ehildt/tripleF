# Retry With Backoff

Run an async task, retrying with exponential backoff (optional full jitter) until it succeeds, the attempts are exhausted, the signal aborts, or a `shouldRetry` predicate declines. The final failure rethrows the last error so callers decide between warning, fallback, or crashing.

## Import

```typescript
import { retryWithBackoff } from "@triplef/helpers/retry-with-backoff";
```

## Signature

```typescript
function retryWithBackoff<T>(
  task: () => Promise<T>,
  options?: RetryWithBackoffOptions
): Promise<T>;
```

## Options

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `attempts` | `number` | `3` | Total attempts including the first one |
| `initialDelayMs` | `number` | `500` | Delay before the first retry; multiplied by `backoffFactor` each attempt |
| `maxDelayMs` | `number` | `16_000` | Upper bound for the per-attempt delay |
| `backoffFactor` | `number` | `2` | Multiplier applied to the delay each retry |
| `jitter` | `boolean` | `true` | Full jitter — random delay between 0 and the exponential delay |
| `signal` | `AbortSignal` | — | Cancels pending retries (the task sees the abort reason) |
| `shouldRetry` | `(error, attempt) => boolean` | always retry | Decline to retry a given error |
| `onRetry` | `(error, attempt, delayMs) => void` | — | Called before each retry |
| `sleep` | `(ms, signal?) => Promise<void>` | `defaultSleep` | Injectable sleep — tests advance time without waiting |

## Example

```typescript
const config = await retryWithBackoff(() => loadRemoteConfig(), {
  attempts: 5,
  initialDelayMs: 250,
  shouldRetry: (error) => isTransientNetworkError(error),
  onRetry: (error, attempt) => logger.warn(`attempt ${attempt} failed`),
});
```

## Used by

The memory app's boot restore of persisted overrides (`BOOT_RESTORE_ATTEMPTS = 5`, 500 ms → 8 s backoff) spans compose cold starts — see **1.7**.
