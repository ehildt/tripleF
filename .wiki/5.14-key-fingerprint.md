# Key Fingerprint

A stable, non-sensitive identifier of a master key — the first 8 hex chars of its SHA-256 digest.

## Import

```typescript
import { keyFingerprint } from "@triplef/helpers/key-fingerprint";
```

## Signature

```typescript
function keyFingerprint(key: Buffer): string;
```

## Why it exists

Every `encryptSecret` payload embeds the fingerprint of the key that produced it, so after a key rotation the decrypt side can pick the right key from the key ring (**crypto agility**, OWASP/ASVS) without leaking any key material. Eight hex chars are plenty to distinguish "current" from "previous" in a two-key ring; they are a label, not a secret.

## Example

```typescript
const ring = new Map([
  [keyFingerprint(currentKey), currentKey],
  [keyFingerprint(previousKey), previousKey],
]);
```
