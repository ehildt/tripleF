# 7.1. Core-Logger Service

A NestJS `LoggerService` backed by pino. It normalizes the call shapes NestJS forwards into pino calls, then invokes an optional per-call `onLog` hook.

## Import

```typescript
import { CoreLoggerService } from '@triplef/core-logger';
```

## Methods

| Method | pino level |
| --- | --- |
| `verbose(message, ...)` | `trace` |
| `debug(message, ...)` | `debug` |
| `log(message, ...)` | `info` |
| `warn(message, ...)` | `warn` |
| `error(message, ...)` | `error` |
| `fatal(message, ...)` | `fatal` |

## Call Shapes

The service accepts every shape NestJS forwards:

```typescript
logger.log('message');
logger.log('message', 'Context');           // context → [Context] message
logger.log('message', { userId: '123' });   // structured meta
logger.log({ userId: '123' }, 'message');   // meta-first form
logger.error('message', stack, 'Context'); // stack → err field
```

## onLog Hook

Pass `onLog` in the meta object to run a fire-and-forget callback after the write. It is stripped before the log is written and invoked error-isolated.

```typescript
logger.info('user signed up', {
  userId: '123',
  onLog: (entry) => sendToDb(entry),
});
```

`entry` is `{ level, message, context?, meta? }`.

## setLogLevels

```typescript
logger.setLogLevels(['log', 'warn', 'error', 'fatal']);
```

Maps the most-verbose enabled NestJS level to the pino threshold; an empty list silences the logger.
