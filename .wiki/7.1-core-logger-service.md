# 7.1. Core-Logger Service

A NestJS `LoggerService` backed by pino. The service owns the pino client and delegates the documented NestJS call shapes to it.

## Import

```typescript
import { CoreLoggerService } from '@triplef/core-logger';
```

## Methods

| Method | pino level |
| --- | --- |
| `verbose(message, ...)` | `trace` |
| `debug(message, ...)` | `debug` |
| `log(message, ...)` | `info` |
| `warn(message, ...)` | `warn` |
| `error(message, ...)` | `error` |
| `fatal(message, ...)` | `fatal` |

## Call Shapes

The service delegates the shapes NestJS forwards:

```typescript
logger.log('message');
logger.log('message', 'Context');                // context → [Context] message
logger.log('message', { userId: '123' });        // structured bindings
logger.log({ requestId }, 'message', 'Context'); // pino object-first form
logger.error(error, 'Context');                  // Error → err binding (type, message, stack)
logger.error('message', error, 'Context');       // same, at any level
logger.error('message', stack, 'Context');       // stack string → stack binding (verbatim)
```

## setLogLevels

```typescript
logger.setLogLevels(['log', 'warn', 'error', 'fatal']);
```

Maps the most-verbose enabled NestJS level to the pino threshold; an empty list silences the logger.
