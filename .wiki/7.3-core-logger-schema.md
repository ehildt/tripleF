# 7.3. Core-Logger Schema

A Joi schema for validating pino `LoggerOptions`. Exported so consumers can validate their own pino config (e.g. via `@ValidateReturnValue`) before handing it to `CoreLoggerModule.registerAsync`.

## Import

```typescript
import { CoreLoggerSchema } from '@triplef/core-logger';
```

## Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `level` | `string` | `info` | One of `fatal`, `error`, `warn`, `info`, `debug`, `trace`, `silent` |
| `base` | `object \| null` | — | pino `base` (keys added to every log line) |
| `transport.target` | `string` | `pino-pretty` | Transport target |
| `transport.options.translateTime` | `string` | `yyyy-mm-dd HH:MM:ss.l` | Timestamp format |
| `transport.options.colorize` | `boolean` | `true` | Colorize output |
| `transport.options.ignore` | `string` | `pid,hostname,context` | Keys hidden from pretty output |
| `transport.options.singleLine` | `boolean` | `false` | Single-line output |
| `transport.options.colorizeObjects` | `boolean` | `true` | Colorize objects |
| `transport.options.messageFormat` | `function` | — | Custom message formatter (e.g. inline `[Context]`) |

Unknown keys are allowed (`.unknown(true)`).

## Usage

```typescript
import { Injectable } from '@nestjs/common';
import { ValidateReturnValue } from '@triplef/config-factory/validate-return-value';
import { CoreLoggerSchema } from '@triplef/core-logger';

@Injectable()
export class LoggerConfigService {
  @ValidateReturnValue(CoreLoggerSchema)
  get options() {
    return {
      level: process.env.LOGGER_LEVEL || 'info',
      transport: {
        target: 'pino-pretty',
        options: {
          ignore: 'pid,hostname,context',
          messageFormat: (log, messageKey) =>
            log.context ? `[${log.context}] ${log[messageKey]}` : String(log[messageKey] ?? ''),
        },
      },
    };
  }
}
```
