# Parse LLM JSON

Parse JSON emitted by an LLM, tolerating the common deviations models produce from the strict JSON spec.

## Import

```typescript
import { parseLlmJson } from "@triplef/helpers/parse-llm-json";
```

## Signature

```typescript
function parseLlmJson(text: string): unknown;
```

## What it tolerates

- thinking-model residue: full `<think>…</think>` blocks or a dangling preamble ending in `</think>` before the output
- `[Template: <name>]` markers echoed before the JSON
- markdown code fences (` ```json `, ` ``` `)
- single-quoted strings
- unquoted object keys
- trailing commas
- literal newlines / control characters inside quoted string values
- bare `undefined` literals (coerced to `null`)
- leading/trailing explanation text around the first top-level JSON object or array

## Behavior

- Throws `SyntaxError("Response is empty.")` on empty input.
- Extracts the **first** top-level `{...}` or `[...]` block and discards the surrounding prose.
- Returns the parsed value; Zod validation is the caller's job (the memory jobs parse tolerantly here, then validate against `@triplef/agent` schemas — see **1.7**).

## Example

```typescript
const verdict = memoryProfileResponseSchema.parse(parseLlmJson(rawModelOutput));
```
