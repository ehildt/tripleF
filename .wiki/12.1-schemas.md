# 12.1. Agent Schemas

`@triplef/agent/schemas` — the Zod contract of the agent domain: what the intent classifier may answer, what the response variants must look like, what the memory jobs emit, and which tools exist at all.

## Import

```typescript
import { /* … */ } from '@triplef/agent/schemas';
```

## Intent schema

`intent.schema.ts` — the classifier's output contract. One of the 14 templates (`article`, `news`, `describe`, `compare`, `ocr`, `summary`, `evaluation`, `product`, `shoplist`, `imagelist`, `videolist`, `stockmarketitem`, `stockmarketlist`, `text`) plus the chosen tool set, image/video counts, recency anchoring, a context summary, and an optional clarification question. Used by the harness interpret step (see **1.2**).

## Response JSON schemas (`response/`)

The machine-readable answer shapes the UI renders from:

| Schema | Feeds |
| --- | --- |
| `ocr`, `describe`, `compare`, `summary`, `product`, `shoplist`, `imagelist`, `videolist` | The matching response variants/templates. |
| `stockmarketitem`, `stockmarketlist` | Stock answers (with `chart-overlays-json` for chart series). |
| `card-json`, `gallery-item-json`, `reference-gallery-item-json`, `video-gallery-item-json`, `related-story-json`, `source-json`, `text-item-json`, `international-coverage-json`, `discarded-reference-json` | Reusable building blocks shared by the variant schemas. |

The snippet-composed templates (`news`, `article`, `evaluation`) build their schemas from snippet presets — see **12.2**.

## Memory schemas (`memory/`)

| Model/schema | Consumed by |
| --- | --- |
| `memory-cognition.model.ts` — the cognition profile Zod model, `normalizeCognitionProfile`, `mergeCognitionProfiles`, `isAllFieldsNullWipe`, and the `clampCognitionLimit` / `clampEpisodeProbeLimit` / `clampEpisodeRecency*` / `clampEpisodeScoreThreshold` bounds | Memory app profile job + overrides service; **1.6** documents the shape. |
| `extraction.schema` | The `vectorize` fact-extract step. |
| `consolidation-verdict.schema` | The consolidate sweep's `keep`/`redundant`/`merge` verdicts. |
| `enrichment.schema` | The relink job's category-collapse output. |
| `cluster-summary.schema` | The cluster job's title/summary output. |

## Tool registry (`helpers/tools/tool-registry.constants.ts`)

The single vocabulary of tool names — `TOOL_NAMES` and its slices `BROWSER_TOOL_NAMES` (the Playwright allow-list, 15 tools) and `MEMORY_TOOL_NAMES` (5 memory tools) — plus the `ProviderConfig` type the harness uses to gate tools per provider (see **1.2** grounding tools). If a tool isn't here, the classifier can't pick it.

## URL trust (`constants/`, `helpers/url-trust/`)

`url-trust.constants` + `blocked-image-hosts`, the `url-schema` helper, and the guards `is-trusted-url`, `is-trusted-image-url`, `is-private-or-localhost` (SSRF guard), `has-blocked-image-host` — the trust boundary from **4-business-logic** made code.

## Zod helpers (`helpers/zod/`)

`derive-schema-keys`, `format-zod-issues`, `format-zod-shape` — used by prompts and validators to render/explain schemas to the model and to log honest validation errors.

## Encyclopedia select model

`encyclopedia-select.model.ts` — the select request/result types shared between the harness (caller) and the memory app (server) — see **1.7**.
