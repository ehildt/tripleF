# Mask API Key

Mask an API key for client display, and detect masked values coming back from a client.

## Import

```typescript
import { maskApiKey, isMaskedApiKey } from "@triplef/helpers/mask-api-key";
```

## Functions

### maskApiKey

```typescript
function maskApiKey(apiKey?: string): string | undefined;
```

Returns a **fixed** run of asterisks (`****************`) — nothing about the real key leaks, not even its length or prefix. `undefined`/`empty` passes through unchanged.

### isMaskedApiKey

```typescript
function isMaskedApiKey(value: unknown): boolean;
```

True when a value looks like a masked key (contains `****`) rather than a real one.

## Why it exists

The provider-overrides API returns masked keys on read. On write, the server must distinguish "client sent back the mask" (keep the stored key) from "client set a new key" — `isMaskedApiKey` is the guard; masked values are never accepted back as real keys. See **1.1** (provider overrides) and **1.5** (secrets cipher).
