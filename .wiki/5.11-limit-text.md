# Limit Text

Cap LLM-facing text **without a silent cut** — if the text exceeds the cap, it is hard-sliced and an explicit marker is appended so the model knows content is incomplete (and must not infer the omitted remainder).

## Import

```typescript
import { limitText } from "@triplef/helpers/limit-text";
```

## Signature

```typescript
function limitText(text: string, maxChars?: number): string;
```

## Behavior

| Input | Result |
| --- | --- |
| `maxChars` undefined / `<= 0` | text unchanged (default = no loss) |
| `text.length <= maxChars` | text unchanged |
| `text.length > maxChars` | `text.slice(0, maxChars)` + truncation marker |

The marker:

```
\n[TRUNCATED — showing <shown> of <total> chars. Do not infer the omitted remainder.]
```

## Example

```typescript
limitText(doc, 100000);
// → first 100k chars + marker, when longer
```

## Used by

The harness caps fetched source documents (`HARNESS_REFERENCE_DOC_*`) and the memory jobs cap payloads (`MEMORY_PROFILE_PAYLOAD_*`, `MEMORY_VECTORIZE_TEXT_*`) — see **1.8**.
