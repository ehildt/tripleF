# 7.2. Core-Logger Module

A dynamic module that wires `CoreLoggerService` to caller-supplied pino `LoggerOptions`.

## Import

```typescript
import { CoreLoggerModule } from '@triplef/core-logger';
```

## Interface

```typescript
interface CoreLoggerModuleOptions {
  global?: boolean;
  inject: Array<any>;
  useFactory: (...deps: any[]) => Promise<LoggerOptions> | LoggerOptions;
}
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `global` | `boolean` | `false` | If `true`, makes the service available throughout the application without explicit import |
| `inject` | `Array<any>` | — | Providers injected into `useFactory` |
| `useFactory` | `(...deps: any[]) => Promise<LoggerOptions> \| LoggerOptions` | — | Factory returning the pino `LoggerOptions` |

## Usage

```typescript
import { Module } from '@nestjs/common';
import { CoreLoggerModule } from '@triplef/core-logger';
import { LoggerConfigService } from './logger-config.service';

@Module({
  imports: [
    CoreLoggerModule.registerAsync({
      global: true,
      inject: [LoggerConfigService],
      useFactory: (config: LoggerConfigService) => config.options,
    }),
  ],
})
export class AppModule {}
```

The env-driven config lives in the consuming app — the library ships no config service and reads no environment variables.

## Bootstrap

```typescript
const app = await NestFactory.create(AppModule, { bufferLogs: true });
app.useLogger(app.get(CoreLoggerService));
```
